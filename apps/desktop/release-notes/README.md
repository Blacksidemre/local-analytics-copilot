güncel feature veya release durumu olarak kullanılmamalıdır. Canonical değişiklik kaydı repository
root [`CHANGELOG.md`](../../../CHANGELOG.md), release kapıları ise
[`docs/RELEASE_CHECKLIST.md`](../../../docs/RELEASE_CHECKLIST.md) içindedir.

release talimatları deprecated'tir.
